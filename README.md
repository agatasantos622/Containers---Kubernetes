# Containers & Kubernetes

Projeto desenvolvido como desafio acadêmico para demonstrar a conteinerização e a orquestração de aplicações utilizando Docker e Kubernetes.

## Objetivo

Implementar dois servidores web (Nginx e Apache HTTPD) utilizando Docker e Kubernetes, tornando ambos acessíveis em portas distintas dentro de um cluster local.

## Tecnologias utilizadas

- Docker
- Kubernetes
- Nginx
- Apache HTTPD
- YAML

> Este projeto está em desenvolvimento.
